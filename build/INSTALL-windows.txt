Pairleaf 0.6.0（原 Folio）— Windows 10 / 11 x64

安装与更新
安装版：运行 Pairleaf-0.6.0-windows-x64-setup.exe，按向导安装或更新。
免安装版：运行 Pairleaf-0.6.0-windows-x64-portable.exe；首次启动会临时解包，无需安装向导。
更新前退出 Pairleaf 或 Folio。安装版按向导更新；免安装版改用新的 EXE。不要同时运行新旧版本编辑同一论文库。
免安装不代表数据自动跟随 EXE。论文和笔记默认仍在「文档/Folio Library」，设置仍在 %APPDATA%\Folio；自定义库路径不变。不要为更名删除数据目录。
本包未使用 Windows 代码签名证书，请从官方 GitHub Releases 下载。

阅读与 AI
导入正文和补充 PDF，核对自动填入的文章名称后确认。拖动 PDF 顶部标签或手柄到另一栏，可交换左右或上下位置，各自的阅读状态保留。
AI 需自行填写 API Key，离线阅读无需 Key；安装包不含个人密钥、论文或笔记。
「智能问答」从所选文档的已提取全文中查找相关片段；「整篇精读」分批处理全部可提取文字，显示进度和范围，并复用本地证据笔记。
整篇精读可以带问题开始，也可留空生成全文摘要，会增加模型调用次数、耗时与费用。智能问答有时也会增加一次检索词转换请求；语音对话使用智能问答。
扫描件尚无 OCR；文字覆盖范围不代表 AI 看到了图片。无法提取文字的页面会提示，请结合原文核对答案。

Windows 语音（实验性）
默认关闭。点击「语音」只打开选项，「开始聆听」才收音；试听不需要 AI Key，也不收音、不写入聊天。
使用本机 System.Speech / SAPI 识别与朗读，无需额外语音 Key，不上传录音。转写文字与论文上下文仍会发送给所选 AI 服务。
需要兼容的本地识别引擎和音色；安装语言包不保证有可用的 SAPI 听写引擎，讲述人的自然音色也不一定可供应用使用。识别不可用时可继续文字输入，不会自动转到云端识别。
语音组件需要 .NET Framework 4.8 或兼容的 4.8.1，较新 Windows 通常已包含；无需安装 .NET 开发 SDK。
Windows 安装、收音、朗读和资源占用尚未实机或虚拟机测试。Mac 上的交叉构建和静态检查不代替 Windows 实测。

English
Installer: run Pairleaf-0.6.0-windows-x64-setup.exe and follow the wizard.
Portable: run Pairleaf-0.6.0-windows-x64-portable.exe; it extracts a temporary application without an installation wizard.
Quit Pairleaf or Folio before updating. Follow the installer, or use the new portable EXE. Do not run both versions against one library.
Portable does not mean your library travels with the EXE. Papers and notes remain in Documents/Folio Library by default; settings remain in %APPDATA%\Folio. Custom library paths are preserved. Do not delete data folders because of the rename.
This build is unsigned; download it from the official GitHub Releases page.

Import the paper and supplements, then check and confirm the suggested title. Drag a PDF tab or grip onto the other pane to swap side-by-side or stacked views while keeping their reading state.
AI requires your own API key; offline reading does not. No personal keys, papers, or notes are bundled. Smart Q&A retrieves passages throughout the selected documents. Full-paper reading processes all extractable text in batches, shows progress and coverage, and reuses evidence notes.
Enter a question for Full-paper reading or leave it blank for a full summary. It makes more model calls and can take longer and cost more; Smart Q&A may make an extra query-expansion request. Voice conversations use Smart Q&A.
OCR is not included, and text coverage does not imply image understanding. Pages without extractable text are reported; check answers against the paper.

Windows speech is experimental and off by default. Voice opens options; Start listening uses the microphone. Preview needs no key or microphone and does not add chat entries.
It uses local System.Speech / SAPI and never uploads recordings. Transcripts and paper context still go to your selected AI provider. Compatible local engines and voices are required; language downloads do not guarantee a usable SAPI dictation engine. Narrator natural voices are not necessarily available to the app. If recognition is unavailable, continue typing; there is no automatic cloud fallback.
The speech helper needs .NET Framework 4.8 or compatible 4.8.1, normally included with recent Windows; no development SDK is required.
Windows hardware/VM installation, microphone capture, playback, and resource use remain untested. Cross-building and static checks on Mac do not replace Windows device testing.
