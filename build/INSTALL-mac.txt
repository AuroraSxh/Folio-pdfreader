Folio 0.4.0 — 学术 PDF 阅读器

适用：macOS 13 或更高版本；此通用安装包包含 Apple Silicon 与 Intel 两种架构。

安装
1. 将窗口中的 Folio 拖入 Applications（应用程序）。
2. 等待复制完成，弹出 Folio 磁盘映像。
3. 从「应用程序」打开 Folio。

首次打开
此版本只有本机 ad-hoc 签名，未做 Apple Developer ID 签名及公证。
如果系统提示无法验证开发者，请先确认安装包来自你信任的发送者。
尝试打开后，可按 Apple 官方说明在「系统设置 → 隐私与安全性」中为此应用选择「仍要打开」。
受组织管理的电脑可能不允许此操作，请联系管理员。
Apple 说明：https://support.apple.com/zh-cn/102445

开始阅读
导入正文 PDF 与补充材料，或先点击「体验示例工作区」。
PDF 右键菜单支持左右/上下分栏和复制。两栏独立缩放，共用荧光笔工具栏。
工具栏位置按钮可切换底部悬浮和顶部固定。
选中文字后，工具栏与右键菜单均可添加高亮、下划线、删除线。
选中文字右键「添加批注」，填写后保存；取消不会创建标记。
已有标记文字或批注小圆点上右键，可编辑、删除批注；侧栏也有「删除批注」。删除包含该条标记和评论，可撤销恢复。
⌘Z / Ctrl+Z 撤销批注或目录编辑，⌘⇧Z / Ctrl+Shift+Z 重做。输入框内撤销文字。
撤销栈在重启后清空；已保存的标记、目录和笔记仍保留。

阅读空间
左侧默认精简导航，点击文件夹展开。AI 可按 ⌘J 展开磨砂浮层，不挤压 PDF。
悬浮时可拖动“阅读伙伴”标题栏自由移动，位置自动记住，窗口变小时会限制在阅读区域内。
标题栏聚焦后支持方向键微调，Home 复位。固定按钮可切换固定/浮出；左边缘可拖动调整宽度。
「专注阅读」或 ⌘⇧F 隐藏导航和 AI，再次点击恢复，保留阅读位置与对话草稿。

AI 与笔记
在「设置与连接」中输入自己的 DeepSeek API Key，并选择自己的 Obsidian 仓库。
安装包不包含发送者的 API Key、论文或笔记。
系统可能询问「Folio Safe Storage」钥匙串授权，用于加密保存 API Key；密码仅在系统弹窗输入。

数据与移除
默认论文库在「文稿/Folio Library」。移除文章后可在侧栏「已移除文章」恢复。
已移除文章不会自动过期，只有再次确认「彻底删除」才永久删除。
设置里的完整 ZIP 备份可以转移论文、笔记及已移除文章，不包含 API Key。

说明
本版支持学术 PDF 阅读、批注与 AI 工作区；扫描件无文字层时不能直接复制或全文搜索，尚未加入 OCR。

语言与更新
在「设置与连接」顶部的「语言 / Language」选择简体中文或 English，并保存。
「应用更新」可检查 GitHub 新版本；下载并通过 SHA-256 校验后，点击打开 DMG，将 Folio 拖入 Applications 替换旧版。
启动时只做一次轻量检查，6 小时内不重复自动检查；可在设置中关闭。

Mac 语音对话
打开文章后，点击阅读工具栏的「语音」，选择中文或英文。首次使用需允许麦克风权限；缺少 Apple 语言模型时，按提示下载。
语音识别与朗读使用 Apple 系统服务，无需额外语音 Key；AI 回答仍需要自己的 API Key。
收起 AI 面板仍可继续语音对话，转写与回答保存在同一聊天记录；支持暂停、打断和结束。
识别可用性取决于设备、系统和语言。真实麦克风与扬声器测试尚未完成。
