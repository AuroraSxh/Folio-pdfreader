# Folio v0.4.1 实现概览

Mac 与 Windows 桌面应用，使用 Electron、React 和 Mozilla PDF.js，数据保存到本地文章文件夹。AI 通过用户配置的远程 API 调用，支持 SSE 流式回复；本地 PDF 阅读不依赖 AI 或网络。

功能范围：论文库；每文多个 PDF；左右或上下分栏，同一 PDF 也可分别阅读不同位置；每栏独立阅读状态、缩放控件与触控板双指捏合；目录读取、增删改排序、导出为 PDF 书签；缩略图、全文搜索、连续/单页/水平/网格滚动、双页、缩放旋转；选文高亮与笔记；打印与另存副本；DeepSeek/OpenAI/Anthropic/兼容接口、流式问答与总结、选文解释、持久对话、多 PDF 上下文、分类记忆与跨文召回；Markdown/Obsidian 幂等导出；完整文件备份恢复。

不包含 Acrobat Pro 的排版编辑、OCR、数字签名、表单创建。扫描件可阅读；无文本层时提示 AI 无可提取正文。PDF 原件以复制方式导入，修改通过工作区与导出副本保存。

阅读交互：两栏共用批注工具栏与荧光笔颜色，工具栏按钮直接切换底部悬浮/顶部固定并保存偏好；原生快捷键、工具栏与右键复制；PDF 右键左右/上下分栏。侧栏「已移除文章」保留完整工作区，可恢复或二次确认后彻底删除，无自动过期清理；完整备份包含已移除文章。

0.4.1 默认关闭语音，重启和重开文章不恢复会话，仅保存音色及语速偏好；修复返回同一文章后旧点击请求重开语音面板的问题。「阅读小贴士」和语音选项均内置中英文离线教程，说明下载音色、设置系统默认及 Folio 独立选择。

0.4.1 改进中英混读：英文词语和短语作为完整单位交给英文音色，增加 CD 标记、fl/fl 基因型、部分细胞因子和实验缩写的读法规则。文件引用不再逐字拼读，聊天原文及可点击引用保留。中英文音色分别选择，显示普通/增强/高级质量，支持不收音、不调用 AI 的试听。仍使用按需启动和空闲退出的原生组件，不增加后台轮询。

0.4.1 正式包验证：构建、149 项单元测试、38 项打包版界面检查通过（语音 12、阅读 20、双语及更新 6）；已安装的高级莉莉和 Ava 通过 9 段真实 Apple 文件合成。自动检查未使用麦克风、扬声器或真实 AI。

0.4.1 较早预览版验证：构建、148 项单元测试、9 项打包版语音界面检查通过；真实 Apple API 完成 9 段中英混合文本的文件合成，真实 IPC 验证音色质量传递及空闲退出。测试没有使用麦克风、扬声器或真实 AI；听感需实际试听。当时仅安装普通音色；后续已验证新下载的月、黎潋、莉莉和 Ava 高级音色可被接口识别。双栏前台性能见 [0.4.1 测量](performance-v0.4.1.md)。

0.4.0 增加 Mac 原生语音对话：使用 Apple 本地识别与系统朗读，语音输入和 AI 回答保存在当前文章的同一对话中，收起 AI 面板仍可操作。支持中文、英文、暂停和打断；朗读期间停止收音。原生组件按需启动、空闲退出；切换文章、锁屏、关闭窗口会停止语音。Windows 暂未接入语音。详见 [语音说明](apple-voice.md)。

0.4.0 验证：构建、121 项单元测试、最终 Mac 通用包的 32 项界面检查通过；真实 Apple API 完成中文合成音频的本地识别。最终包的麦克风用途声明、录音权限配置、双架构及签名完整性已检查，但仍为临时签名，未做 Developer ID 签名或公证。真实打包版 IPC 验证了组件按需启动和空闲退出。麦克风实录与扬声器播放留待用户手动测试，未调用真实 AI 服务。本次发布 Mac 0.4.0，Windows 安装包继续提供 0.3.0。

0.4.0 阅读性能：M1 Pro 前台双栏静置时，AI 关闭、浮出、固定三个场景的 CPU 均值分别为 0.497%、2.835%、0.439%（100% 为一个逻辑核心）；全部 48 个采样均保持前台。此次没有开启语音，不能据此推断连续语音的资源占用。[完整测量与限制](performance-v0.4.0.md)。

验证：v0.3.0 通过 TypeScript 与 91 项单元测试；最终 Mac 通用包在 Apple Silicon 上通过 20 项阅读回归、6 项双语及更新界面检查。GitHub 正式版信息已通过真实接口读取；下载错误和校验边界使用模拟响应测试，测试中不执行安装程序。Intel Mac 未单独运行验证。Windows 安装版与免安装版通过 5 项静态包检查，尚未完成真实 Windows 运行验证。AI 协议使用本地模拟服务器验证，不代表真实模型调用成功。测试截图与报告是本地运行产物，不包含在源码仓库中。

v0.3.0 前台性能抽测：M1 Pro，100 页正文与 40 页补充 PDF，独立 100% 缩放，六个场景各测 8 秒。AI 关闭、浮出、固定时静置 CPU 均值分别为 0.738%、2.765%、0.349%；双栏滚动分别为 7.117%、8.332%、6.374%（100% 为一个逻辑核心）。所有采样保持前台。短时结果受文件内容和共享桌面环境影响；AGX 的 GPU 数据是系统总量，不能归因于 Folio。各场景进程工作集总和约 974–1125 MiB，可能重复计算共享内存，不能等同于独占内存。

0.2.0：默认48px导航与按需AI磨砂浮层；可固定/调宽/专注阅读并记住本机布局。共享工具栏和右键支持三种文字标记，跨PDF按顺序撤销/重做批注及目录，输入框保留原生文字撤销。历史有界且仅当前会话有效；PDF/Obsidian导出保留标记类型。

0.2.1：磨砂 AI 浮层可拖动标题栏移动，记住位置，窗口或导航尺寸变化时限制在阅读区域内；支持键盘移动及 Home 复位。拖动仅按需更新浮层样式，松手才保存位置，不引入空闲定时器。固定侧栏保留原行为。

0.2.2：选中文字右键添加批注，引用和位置由右键时的选区快照保留；已有标记文字和批注图标右键支持编辑、删除，侧栏显示文字删除入口。删除复用原有工作区撤销历史。标记命中仅在右键时检查，不阻挡PDF文本选择、不添加空闲循环。

0.3.0：中英文界面与原生菜单切换，偏好持久化，不改动已有论文、对话和笔记内容。应用内检查 GitHub 正式版，选择匹配系统的安装包，流式下载并验证大小和 SHA-256；用户点击后打开 DMG/安装程序。启动只检查一次，6 小时内复用检查记录，可关闭自动检查。无后台定时轮询。

发布约定：每次发布都在 README.md 与 README.zh-CN.md 的更新记录中补上版本号和主要变化，最新版本在前，保留历史记录，并同步下载链接及 GitHub Release 说明。
