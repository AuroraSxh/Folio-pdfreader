# Folio 0.4.1 性能记录

2026-09-22，在 M1 Pro、10 个逻辑核心、16 GiB 内存、macOS 26.2 上测试最终 Mac 通用包。窗口采用 2 倍显示缩放，打开合成的 100 页正文和 40 页补充 PDF，两栏分别为 100% 缩放。六个场景各采样 8 秒；前四个场景的 32 个采样均处于前台且可见。

| 场景 | CPU 时间加权均值 | 进程工作集均值（MiB） |
| --- | ---: | ---: |
| AI 关闭，静置 | 0.635% | 1208.912 |
| AI 关闭，滚动 | 7.573% | 1217.771 |
| AI 浮出，静置 | 2.435% | 976.904 |
| AI 浮出，滚动 | 7.667% | 949.303 |

「AI 固定，静置」有 1/8 个采样失去前台焦点，随后「AI 固定，滚动」全程不在前台，因此这两个场景不计入上表或前台性能结论；未反复强制抢回焦点。已在原始报告中标为警告，无其他检查失败。

CPU 的 100% 表示占用一个逻辑核心。进程工作集相加可能重复计算共享内存，不能等同于独占内存。短时、固定顺序测量受 PDF 内容、缓存、窗口大小和共享桌面环境影响，不能据此断言版本间性能改善或回退。

AGX 报告的是系统 GPU 总量，上表四个场景的均值依次为 8.625%、16.75%、8.375%、17.125%；无法从中单独归因 Folio 的 GPU 使用率。

本次阅读测量未开启语音。真实打包版 IPC 检查确认：启动时没有语音组件，首次查询才启动，闲置后自动退出；界面测试确认重开文章和重新加载不会自动恢复语音，浏览离线教程也不查询语音服务。

实机枚举到 180 个普通音色和 5 个高级音色（莉莉、黎潋、月、美嘉、Ava）。真实 Apple 文件合成使用高级莉莉与 Ava 完成 9 段中英混合文本，包括 CD4+ 和 fl/fl 的朗读别名；临时音频随后删除。此次合成约 2.34 秒，未使用麦克风、扬声器或 AI。文件合成不按实时播放速度执行，不代表持续语音对话的开销，也不是听感评估。

连续语音的 CPU/GPU 使用率、Intel Mac 性能及旧版 macOS 尚待实机验证。
