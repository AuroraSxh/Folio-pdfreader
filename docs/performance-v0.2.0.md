# Folio v0.2.0 阅读布局性能实测

2026-09-21 23:13（北京时间），在 Apple M1 Pro、10 个逻辑核心、16 GiB 内存、2× 屏幕缩放上测试最终 Mac universal 包。完整运行 59.23 秒，48 个采样点全部处于可见、聚焦状态；各阶段开始和结束的 12 次系统前台 PID 检查也均为测试实例。只激活一次，未重复抢焦点；测试实例已退出，无运行错误。

使用隔离文献库中的 100 页正文和 40 页补充 PDF，每页包含密集文字和栅格图。两个窗格均为 100% 缩放，每个滚动阶段均从顶部移动 16 × 540 = 8640 CSS 像素；各阶段先预热缓存，再测量 8 秒。没有填写 API Key、发送 AI 请求或修改系统桌面偏好。

CPU 根据所有测试进程的累计 CPU 秒差除以墙钟时间计算，**100% 表示占满一个逻辑核心**。工作集是进程总和，共享页可能重复计数，不能直接当成私有内存。

玻璃浮层实际启用了 `blur(12px)`；关闭和浮层布局的 PDF 视窗均为每栏 723 × 646 CSS 像素。固定侧栏无模糊，视窗宽度为 543 像素。三个布局均保持 20 个已分配画布，共 71,179,680 像素，单画布最大 3,558,984 像素，没有因浮层增加 PDF 画布数量。

本次玻璃浮层滚动的 CPU 均值比关闭 AI 高 1.316 个百分点，约高 20.2%。玻璃静止阶段前六个采样点均值约 0.46%，最后两个点升至 11.27% 和 9.45%，同时工作集从 1243.7 MiB 降至 1190.0 MiB；额外 CPU 主要出现在渲染器与主进程。这个现象可能涉及内存回收，但没有 GC 跟踪证据，不能认定是模糊导致的持续开销，也不能删除这两个采样点来降低报告均值。后测阶段内存较低同样不能直接解释为某种布局更省内存。

`ioreg` 记录的**整机 GPU**平均占用，静止／滚动分别为：关闭 AI 6.50%／17.38%，玻璃浮层 6.75%／17.50%，固定侧栏 6.38%／19.88%。这些数据包含 WindowServer 和其他应用，**不能归因于 Folio**。这是一次固定顺序的短测，不能推导电池续航或长期内存稳定性。
