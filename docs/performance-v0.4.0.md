# Folio 0.4.0 性能记录

2026-09-22，在 M1 Pro、10 个逻辑核心、16 GiB 内存、macOS 26.2 上测试最终 Mac 通用包。窗口采用 2 倍显示缩放，打开合成的 100 页正文和 40 页补充 PDF，两栏分别为 100% 缩放。六个场景各采样 8 秒，48 个采样均处于前台且可见，没有检查失败或警告。

| 场景 | CPU 时间加权均值 | 进程工作集均值（MiB） |
| --- | ---: | ---: |
| AI 关闭，静置 | 0.497% | 1032.756 |
| AI 关闭，滚动 | 8.366% | 1044.438 |
| AI 浮出，静置 | 2.835% | 1029.852 |
| AI 浮出，滚动 | 7.896% | 953.113 |
| AI 固定，静置 | 0.439% | 917.281 |
| AI 固定，滚动 | 5.840% | 930.258 |

CPU 的 100% 表示占用一个逻辑核心。进程工作集相加可能重复计算共享内存，不能等同于独占内存。短时测量受 PDF 内容、缓存、窗口大小和共享桌面环境影响。

AGX 报告的是系统 GPU 总量，六个场景的均值依次为 8.125%、13.375%、7.125%、17.75%、6.125%、14.5%；无法从中单独归因 Folio 的 GPU 使用率。

本次阅读测量未开启语音。另一次真实打包版 IPC 检查确认：启动时没有语音组件进程，首次查询才启动，闲置后自动退出。中文原生测试使用 Apple 朗读生成临时音频，再通过 Apple 本地识别转写，未使用麦克风或扬声器。单次组件测试耗时约 1.67 秒、峰值 RSS 约 38.9 MiB；该数据不包含 Apple 系统语音服务，也不代表持续收音或真实 AI 对话的开销。

麦克风实录、可听播放、连续语音的 CPU/GPU 使用率及 Intel Mac 性能尚待手动验证。
